Specula 监视你自托管的服务，一眼告诉你哪些在正常运行、哪些变慢了、哪一个刚刚宕机。

无需账号，没有中间服务器，没有遥测：应用直接查询你网络中的设备。你的 API 密钥始终留在自己的设备上。

一块仪表板，而不是一堆链接

每个服务都通过其 API 显示真实指标：Immich 的照片数量、AdGuard 拦截的请求、NAS 的剩余空间、Proxmox 的容器、正在填满的存储卷。服务类型会被自动识别——Immich、Nextcloud、Home Assistant、Proxmox、OpenMediaVault、UniFi、Portainer、Vaultwarden、Paperless 等等。

三分钟即可上手

扫描你的网络，Specula 会自动发现服务。或者导入你已经在 Homepage 中使用的 services.yaml——分组、网址和小组件原样沿用。也可以手动添加地址。

真正重要的故障

某个服务连续三次无响应即触发通知。状态墙保留三十天历史记录，并计算每个服务的实际可用率。各项提醒——服务离线、磁盘写满、温度过高——可逐条开启；本就该写满的存储卷，一键排除。

无论你在哪里查看

iPhone、iPad、Mac，主屏幕和锁定屏幕上都有小组件，故障期间显示实时活动，Mac 上还可从菜单栏访问。每个服务只需一个地址：从你的设备能连通的那一个，无论走局域网、VPN、反向代理还是隧道。

先试用，再配置

完整的演示模式提供模拟数据，无需安装任何东西即可看到应用的运行效果。
