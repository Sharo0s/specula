Specula 监视你自托管的服务，一眼告诉你哪些在正常运行、哪些变慢了、哪一个刚刚宕机。

无需账号，没有中间服务器，没有遥测：应用直接查询你网络中的设备。你的 API 密钥始终留在自己的设备上。

每个服务都通过其 API 显示真实指标：Immich 的照片数量、AdGuard 拦截的请求、NAS 的剩余空间、Proxmox 的容器。六十多种服务类型会被自动识别。

iPhone、iPad、Mac，主屏幕和锁定屏幕上都有小组件，故障期间显示实时活动，Mac 上还可从菜单栏访问。

无需安装即可测试

演示模式在引导流程中即可开启，用模拟数据填满应用。你无需提供任何地址就能浏览全部功能。

用你自己的服务测试

三种入口：扫描网络、导入 Homepage 的 services.yaml，或手动添加地址。前四个服务免费。

TestFlight 内购免费

额外名额和「无限服务」选项均走沙盒环境：不会向你收取任何费用。请务必试用，这很有帮助。

反馈问题

截屏后在 TestFlight 中选择「发送反馈」，或在 github.com/Sharo0s/specula 提交 issue。请注明服务名称与类型：多数偏差源自某个 API 的响应方式与预期不同。
